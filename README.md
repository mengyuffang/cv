# Interactive CV starter

This branch contains a minimal Next.js + TypeScript starter for an interactive CV + portfolio as described by the owner.

What's included:
- Next.js App Router structure (TypeScript)
- Global theme variables matching the brief (dark background, warm ivory text, copper accent)
- Simple Hero + Project grid
- Project card -> full-screen detail overlay demo (CSS + optional GSAP hooks)
- Instructions to install dependencies and run locally

Run locally:
1. npm install
2. npm run dev

Notes:
- This is a starter scaffold. Add your project content in app/page.tsx or create data files under /data.
- To enable GSAP/Lenis interactive behaviors, npm install has already included the packages; the demo shows where to initialize them.
